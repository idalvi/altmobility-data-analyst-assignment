# Alt Mobility Data Analyst Internship Assignment

## 🏢 About Alt Mobility

Alt Mobility is a fast-growing EV leasing and asset management company managing a fleet of 20,000+ vehicles across India. This repository contains the SQL-based analysis and visualizations required for the Data Analyst Intern assessment.

---

## 📁 Folder Structure
SQL/->SQL queries for analysistasks
Visualizations/->Chart/Graph for retention

---

## 📊 SQL Tasks

### 1. Order and Sales Analysis

- *Objective*: Analyze order fulfillment and revenue trends.
- *Query*: task_1_order_sales_analysis.sql
- *Metrics*:
  - Order counts by status
  - Total and average revenue
- *Insights*:
  - Shows revenue contributions and delays across order statuses.

---

### 2. Customer Analysis

- *Objective*: Explore customer behavior and repeat purchase patterns.
- *Query*: task_2_customer_analysis.sql
- *Metrics*:
  - Repeat vs one-time customers
  - First/last order dates
- *Insights*:
  - Helps segment users and assess customer loyalty.

---

### 3. Payment Status Analysis

- *Objective*: Investigate successful and failed payments.
- *Query*: task_3_payment_status_analysis.sql
- *Metrics*:
  - Number and sum of payments per status
- *Insights*:
  - Identifies technical or transactional issues with payments.

---

### 4. Order Details Report

- *Objective*: Provide unified view of orders and corresponding payment data.
- *Query*: task_4_order_details_report.sql
- *Metrics*:
  - Order ID, amount, status, payment method/status
- *Insights*:
  - Links transactions to customer orders for further investigation.
